# A·B·C 고객 사용성 비교 설문

## 현재 상태
- C안 경로: /reform-choice. A와 B 유지, 비교 메뉴에 C 추가.
- Google Forms 자동 생성 코드: tools/create-abc-survey.gs
- 실제 Google 계정에는 아직 생성되지 않음. 브라우저/컴퓨터 도구가 `failed to write kernel assets` 오류로 초기화에 실패함.
- 자동 생성 코드는 Google 공식 FormApp API 기준이며, Google 계정에서의 실행은 미검증. 처음 생성은 미게시 상태. 재실행은 동일 폼 링크 반환. 생성 도중 실패하면 부분 초안 여부를 먼저 확인.

## 태연님이 폼을 만드는 방법
1. https://script.google.com/ 에서 Google 계정으로 로그인하고 새 프로젝트를 엽니다.
2. 기본 코드를 지우고 tools/create-abc-survey.gs 전체를 붙여넣어 저장합니다.
3. 실행할 함수 createReformABCForm을 선택하고 실행합니다. Google 권한 요청이 나오면 요청 범위를 직접 확인합니다.
4. 실행 로그에 나타나는 ‘설문 편집 링크’를 엽니다.
5. 소개문, 질문, 이메일 미수집 설정, 응답자 접근 범위 및 조직 로그인 제한 여부를 검토합니다. 공유 전 담당자 연락처·응답 보관 기간을 확정해 소개문에 추가합니다.
6. 폼을 미리보기로 확인한 뒤 게시하고 응답자 링크를 복사합니다. 실제 응답 전 모바일과 로그아웃 상태에서도 접근 가능한지 확인합니다.

공식 API: https://developers.google.com/apps-script/reference/forms/form-app

## 고객이 볼 화면
현재 localhost/127.0.0.1 주소는 태연님 컴퓨터에서만 열립니다. 이를 구글 폼에 외부 체험 링크로 넣으면 안 됩니다.
이번 폼은 대면 또는 화면 공유 진행자가 A/B/C를 보여주는 방식으로 준비했습니다. 고객이 직접 누르는 것과 캡처·영상 평가를 구분해 기록합니다. 원격 독립 체험은 별도 테스트 사이트 배포를 결정한 뒤 진행합니다. 이 작업에서 운영 사이트 배포는 하지 않습니다.

## 공통 과제
1. 흰 면 반팔 티에 작은 얼룩이 있습니다. 해볼 만한 방법과 먼저 확인해야 할 조건을 찾아주세요.
2. 직접 작업할 자신이 없습니다. 전문가에게 맡기는 경로를 찾아주세요.

모두 같은 크기·기기에서 보여줍니다. C를 더 좋다고 소개하지 않습니다. 6가지 순서(ABC, ACB, BAC, BCA, CAB, CBA)를 번갈아 배정합니다. 각 안에서 약1분씩 찾아보고 중간에 정답을 알려주지 않습니다.

## 설문 구성 (자동 생성 파일과 동일)
- 시작: 흰티 손상 경험, 체험 방식, 본 순서 (3문항)
- 각 A/B/C: 얼룩 방법 찾기 성공, 맡기는 경로 찾기 성공, 쉬움1~5, 다음 행동 이해, 찾은 방법/조건 자유응답, 막힌 부분 (각6문항)
- 최종: 가장 쉬운 안(동점·모두 어려움·비교불가 포함), 이유, 원하는 첫 화면 시작 방식, 직접/맡기기 의향, 필요한 정보, 실제 접수 가능하다는 오해 여부 (6문항)
- 총27문항, 자유응답9문항은 선택. 화면을 보지 못한 응답자를 위한 선택지 포함.
- 이메일/이름/전화번호/파일 수집 없음. 결과 요약은 응답자에게 공개하지 않음.

## 판단 기준
예쁘다는 투표만으로 결정하지 않습니다. 실제 직접 조작 참여자의 과제 성공률과 막힌 지점을 우선 확인합니다. 화면 공유/캡처 참여자의 응답은 별도로 봅니다.
- 안별 ‘혼자 찾음’ 비율, 쉬움 평가, 다음 행동 이해 비교
- 보지 못함은 해당 안 평가 분모에서 제외
- ‘준비 중’을 실제 주문 가능으로 오해한 응답은 문구 수정 근거
- 처음에는 소규모 탐색으로 반복되는 불편을 찾아 수정. 작은 표본의 선호를 시장 전체 선호로 단정하지 않음
- 결과가 나오면 A의 작품 증거/B의 고민 탐색/C의 시작 경로를 조합할 수 있음
