# 고객 조사와 홈페이지 제작 계획 · 2026-11-21

## 이번 조사에서 결정할 것
흰 반팔 티 한 품목으로 시작합니다. 화면이 예쁜지보다 고객이 자기 옷에 가능한 방법과 다음 행동을 찾는지 확인합니다. A는 기존 작품 중심 홈페이지, B는 고민을 고르는 리폼 찾기입니다. 실제 접수·결제는 아직 운영하지 않습니다.

## 구글 폼 복사용 초안
제목: 안 입는 흰 티셔츠, 다시 입을 수 있다면?
소개: 흰 반팔 티를 다시 입는 방법을 찾는 홈페이지를 준비하고 있습니다. 이용 의향이 없어도 솔직히 답해주세요. 약 4분이며 이름·전화번호·이메일은 받지 않습니다. 답변은 서비스 기획에만 활용합니다. 사진을 제출하거나 주문하는 설문이 아닙니다.
폼 운영 메모: 이메일 수집 없이 진행. 연락처가 필요한 후속 인터뷰 모집은 별도 폼으로 분리. 응답 보관 기간과 담당 연락처는 태연님이 확정해 소개문에 추가. 선택 응답과 기타 직접 입력을 허용하고 불필요한 필수 문항은 두지 않습니다.

1. 최근 1년 동안 잘 입지 않게 된 흰 반팔 티가 있었나요? [객관식]
- 있었다 / 없었다 / 기억나지 않는다

2. 가장 최근 그 흰 티를 안 입게 된 이유는 무엇인가요? [객관식, 한 가지]
- 얼룩·이염 / 작은 구멍·뜯어짐 / 디자인이 마음에 안 들어서 / 크기·핏 / 늘어남·변색 / 기타 / 해당 없음

3. 그 옷은 실제로 어떻게 하셨나요? [객관식]
- 그대로 보관 / 집에서만 입음 / 직접 세탁·수선·장식 시도 / 수선집·전문가에게 맡김 / 기부·나눔·판매 / 버림 / 기타 / 해당 없음

4. 그때 해결하려고 알아보거나 시도한 방법이 있다면 적어주세요. [단답, 선택]
예: 어디에서 찾았는지, 어떤 점이 어려웠는지. 시도하지 않았다면 그 이유도 좋아요.

5. 그 흰 티를 다시 입는다면 어떤 결과가 가장 중요한가요? [객관식]
- 흔적을 최대한 줄이고 원래처럼 / 무늬나 색을 더해 새롭게 / 오래 편하게 입을 수 있게 / 새로 사는 것보다 부담 적게 / 다시 입을 생각이 없음 / 기타 / 해당 없음

6. 이런 홈페이지에서 가장 먼저 확인하고 싶은 정보 두 가지는 무엇인가요? [체크박스, 최대 2개]
- 내 옷에 적용 가능한지 / 비슷한 옷의 실제 전후 사례 / 예상 비용 / 작업 기간 / 세탁·내구성 / 작업자와 작업 과정 / 맡기고 받는 방법 / 직접 하는 재료·방법 / 기타

7. 리폼을 이용할 때 가장 망설여지는 점은 무엇인가요? [객관식]
- 결과가 마음에 안 들까 봐 / 옷이 손상될까 봐 / 비용 / 맡기고 받는 번거로움 / 시간이 오래 걸림 / 원단·방법을 몰라 선택이 어려움 / 특별히 없음 / 이용할 생각 없음 / 기타

8. 현재 가장 가까운 선택은 무엇인가요? [객관식]
- 설명과 재료가 있으면 직접 해보고 싶음 / 전문가에게 맡기고 싶음 / 조건을 비교한 뒤 결정 / 둘 다 관심 없음 / 기타

9. 이전에 옷 수선·리폼에 돈을 쓴 적이 있나요? [객관식]
- 없음 / 있음 / 기억나지 않음
9-1. 있다면 어떤 작업에 얼마 정도 쓰셨나요? [단답, 선택]
가격을 미리 제시해 유도하지 않습니다. 이 답변만으로 서비스 가격을 확정하지 않습니다.

10. 설명·사진만 보고 결정하기 어렵다면 어떤 확인이 필요할까요? [단답, 선택]

11. 홈페이지에 꼭 있었으면 하는 것 또는 없어도 되는 것이 있나요? [장문, 선택]

12. 짧은 화면 비교에서 느낀 점이 있다면 적어주세요. [장문, 선택]
화면을 보지 않은 응답자는 건너뜁니다. 화면 비교는 아래 절차로 별도 진행합니다.

## A/B 화면 확인 · 진행자용 (약 10분)
- 위 요구 조사부터 받고 시안을 보여줍니다. 기존 고객뿐 아니라 리폼 경험 없는 사람, 옷을 그냥 버리거나 보관한 사람도 포함합니다.
- 첫 탐색은 5~8명 정도의 소규모로 시작합니다. 통계적 대표성이나 시장 수요 확정으로 해석하지 않습니다. 가까운 지인 응답만으로 결론 내리지 않습니다.
- 절반은 A→B, 나머지는 B→A 순서로 보여줍니다. 더 좋아 보인다는 설명은 하지 않습니다.
- 동일 과제: ‘흰 면 반팔 티에 작은 얼룩이 생겼습니다. 이 사이트에서 해볼 만한 방법과 먼저 확인해야 하는 조건을 찾아보세요.’
- 중간에 정답을 알려주지 않고 어디를 눌렀는지, 멈춘 곳, 도움 필요 여부를 기록합니다.
- 각 화면을 본 직후 질문: ① 어떤 방법을 찾았나요? ② 내 옷에 안 맞을 수 있는 조건은 무엇인가요? ③ 다음에는 무엇을 할 것 같나요? ④ 지금 실제 주문이 가능하다고 느꼈나요? ⑤ 찾기 쉬웠나요? (1 매우 어려움~5 매우 쉬움)
- 마지막 선택: A가 더 찾기 쉬움 / B가 더 찾기 쉬움 / 차이 없음 / 둘 다 어려움. 이유를 자유롭게 받습니다.
- 비교 기록: 익명번호, 본 순서, 각 버전 과제 성공/부분성공/실패, 걸린 시간(참고), 막힌 지점, 조건 이해, 운영 여부 오해, 선호 이유.
- 지금의 127.0.0.1 주소는 태연님 컴퓨터에서만 열립니다. 설문에 외부 공유 주소로 넣지 않습니다. 대면·화면 공유로 진행하거나 동일 크기의 캡처/화면 녹화를 제공합니다. 정지 화면은 실제 클릭 사용성 검증과 구분합니다.
- 외부 접속용 테스트 사이트는 별도 승인을 받고 준비합니다. 이번 작업은 배포하지 않습니다.

## 결과를 홈페이지로 옮기는 순서
1. 조사: 실제 옷 고민과 고객이 먼저 찾는 정보 확인.
2. 운영 정의: 흰 면 티에 제공 가능한 기법, 불가 조건, 가격 범위, 기간, 상담·접수 방식을 태연님이 확정.
3. 화면 수정: 두 버전의 과제 성공률·혼란 지점을 비교. 선호 투표만으로 선택하지 않고 A의 작품 증거와 B의 선택 흐름을 필요에 따라 결합.
4. 재확인: 수정한 화면을 처음 보는 고객에게 같은 과제로 점검.
5. 서비스 구현: 운영 확정 후 관리자 콘텐츠 관리, 상담/접수부터 연결. 주문·결제·배송·AI 합성은 각각 필요성과 구현 범위를 따로 결정.
6. 출시: 모바일 사용성, 접근성, 실제 제공 문구, 개인정보 처리, 운영 대응을 검토한 뒤 별도 배포 승인.
